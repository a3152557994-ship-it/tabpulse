万站回音（TabPulse）隐私政策 (Privacy Policy)

生效日期 / Effective Date: 2026-11-17 · 严格遵循《个人信息保护法》与 GDPR 最小必要原则

1. 核心承诺：您的账号与私信 100% 留在您自己的电脑上

  • 零云端代存凭证：您在万站回音内置窗口中登录任何第三方网站产生的 Cookie、登录态及页面内容，100% 存储在您个人电脑的本地系统目录（~/Library/WebKit 与 ~/Library/Application Support/TabPulse）中，绝不上传至任何开发者服务器。
  • 离线激活码校验：软件专业版激活码采用 Ed25519 公钥离线算法在您本机直接完成验证，无需上传您的电脑硬件隐私数据。

2. 外部网络请求说明（Network Transparency）

  • 当您主动使用「24h 全网求购扫描器」时，您的设备会直接向 Reddit 公开索引、Hacker News Algolia 与 GitHub 公开搜索接口发起关键词检索请求。
  • 当您自行配置「手机推送 Webhook（如飞书、Bark、Slack）」时，提醒摘要将由您本机直接发送至您填写的 Webhook 地址，不经过任何中间服务器。
  • 当您点击「检查更新」时，软件仅读取 GitHub Pages 上的静态版本号文件 version.json。

3. 数据清除与用户权利（Data Deletion）

您可随时在软件内删除任意盯守站点，或直接移除本地目录 ~/Library/Application Support/TabPulse 彻底清空全部本地配置。如有任何隐私疑问，请联系：a3152557994@gmail.com。
